# Inter

Bundled static instances of Inter from the [Google Fonts Inter directory](https://github.com/google/fonts/tree/main/ofl/inter),
licensed under the [SIL Open Font License 1.1](OFL.txt).

Generated from `Inter[opsz,wght].ttf` with fontTools `instantiateVariableFont`, `opsz=14`,
weights 400 (Regular) and 500 (Medium), and `updateFontNames=True`.
Keeping the exact font files here makes chart rendering independent of installed system fonts.
SVG exports outline the text so the font does not need to be installed to display the charts.
