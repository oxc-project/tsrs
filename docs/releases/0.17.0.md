- **Build memory.** `tsrs -b` now frees each project's program after building it, fixing arena exhaustion on large project graphs. Also fixes a use-after-free in incremental builds and build watch mode (#607).
- **Native packages.** npm binaries omit duplicate embedded TypeScript libraries and read the libraries shipped beside the executable (#578).
- **Compiler maintenance.** Diagnostic timings are collected only when requested, dormant instrumentation is removed, Unicode casing uses compact generated tables, and compiler-option change checks share their traversal (#584, #585, #590, #592, #602, #610).
- **Language-server validation.** CI and release builds now run the pinned upstream Go fourslash harness against the Rust server, replacing the translated suite (#594).
- **Playground.** The [browser playground](https://tsrs-playground.void.app) deploys after each successful release (#526, #587).

The TypeScript source pin is unchanged: `microsoft/TypeScript@b85298b6a81f`. Release binaries report the matching nightly `7.1.0-dev.20260930.4`.
