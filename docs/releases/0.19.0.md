# 0.19.0 beta

Ports the 112 TypeScript commits in [#623](https://github.com/oxc-project/tsrs/issues/623), from the previous
`b85298b6a81f` pin through `microsoft/TypeScript@5237fd468909`, then advances to the `v7.1-beta` tag
(`3e9236361fa9`). Release binaries report the matching npm version, `7.1.0-beta`.

With the upstream emit sequence, the pinned compiler matches all 13,700 error baselines and all 12,998 `.types`
and `.symbols` baselines in both checker histories. Checking-only harness runs retain four diagnostic artifacts.
Emit matches all 13,626 `.js`, 149 `.js.map`, and 156 `.sourcemap.txt` baselines. The port adds source-phase
imports, the current ESNext libraries, Node API and SDK updates, and compiler, build, watch, and language-server
parity fixes. See the
[source-upgrade log](../../notes/typescript-623-ports.md) and
[beta follow-up log](../../notes/typescript-7.1-beta-ports.md) for per-commit conformance and performance evidence.

- **Compiler and build fixes.** Mapped types in JavaScript JSDoc heritage no longer panic; lazy mapped-type
  resolution and empty CommonJS module narrowing preserve Go's behavior. Builds reclaim package-cache entries
  with their final cache generation and limit outstanding program frees. Parent-path normalization handles
  multibyte UTF-8 names without panicking (#698, #652, #675, #703, #713).
- **Language-server API sessions.** `custom/initializeAPISession` exposes the language server's projects and
  unsaved files to Node API clients. Explicit LSP shutdown closes pending and connected API sessions. Mapper
  contributions, including output extensions, are validated and forwarded to the project session; language-server
  mapper execution remains unported (#726).
- **Incremental declaration parsing.** Lazy declaration members now apply to incremental compilation with
  `skipLibCheck` or `noCheck`, and to non-watch project builds when every selected project skips declaration
  checking. `TSRS_LAZY_DTS=0` disables the optimization; watch and API sessions remain eager. See the
  [change's measurements](../../notes/mem-lazy-dts-build.md) for the public reproduction (#727).
- **WebAssembly hosts.** Direct memory views avoid a Cloudflare Workers `subarray` failure above 128 MiB that
  could silently hide input files (#728).
- **Compiler internals.** Instantiated symbols use compact 16-byte headers, reparsing shares one cloner per file,
  and config/resolver hosts are borrowed for their actual lifetime. The checker also reuses cached union metadata
  when narrowing references. Individual measurements are recorded in the
  [symbol-layout](../../notes/mem-compact-symbol-header-results.md),
  [reparse-cloner](../../notes/perf-reparse-cloner.md), and
  [union-memo](../../notes/perf-narrowable-reference-union-memo.md) notes (#732, #716, #719, #715).
- **Project-local VS Code SDK.** The package includes an executable `tsdk/tsgo` launcher for macOS and Linux.
  Set `js/ts.tsdk.path` to `./node_modules/tsrs/tsdk` to select the installed compiler. Windows SDK discovery still
  requires a native executable and is not provided by this launcher (#708).
- **Prebuilt platforms.** The release pipeline adds Intel macOS (`@tsrs/darwin-x64`) and Windows x64
  (`@tsrs/win32-x64`), alongside macOS arm64 and Linux x64/arm64 GNU/musl packages. The Windows CLI returns through
  the C runtime so PGO training can write its profile before shutdown.

Known gaps remain in the [compatibility table](../COMPATIBILITY.md): mapper fixtures are partly skipped by the
compiler and Fourslash harnesses, and language-server mapper execution remains unported. As in pinned Go, LSP EOF
or context cancellation alone leaves an API listener pending when no client has connected; explicit LSP shutdown
closes it. Source 75 increased peak RSS by about 20% on a synthetic two-builder graph; the port log records the
measurement and mitigation review. These and the linked optimization measurements describe individual changes,
not a new packaged-release performance comparison.

All nine npm packages are prepared for the `latest` tag; GitHub marks this version as a prerelease. The public
playground deploys after publication. npm's `beta` tag is assigned manually.

Install the native compiler with `pnpm add -D tsrs@0.19.0-ts7.1.0-beta`.
Install WebAssembly with `pnpm add @tsrs/wasm@0.19.0-ts7.1.0-beta`.
