# 0.19.0

Ports the 112 TypeScript commits in [#623](https://github.com/oxc-project/tsrs/issues/623), from the previous
`b85298b6a81f` pin through `microsoft/TypeScript@5237fd468909`, then advances to the `v7.1-beta` tag
(`3e9236361fa9`). Release binaries report the matching npm version, `7.1.0-beta`.

The pinned compiler matches 13,696 of 13,700 error baselines (the other four are harness artifacts) and all
12,998 `.types` and `.symbols` baselines in both checker histories. Emit matches all 13,626 `.js`, 149 `.js.map`,
and 156 `.sourcemap.txt` baselines. The port adds source-phase imports, the current ESNext libraries, Node API
and SDK updates, and compiler, build, watch, and language-server parity fixes. See the
[source-upgrade log](../../notes/typescript-623-ports.md) and
[beta follow-up log](../../notes/typescript-7.1-beta-ports.md) for per-commit conformance and performance evidence.

Known gaps remain in the [compatibility table](../COMPATIBILITY.md): mapper fixtures are partly skipped by the
compiler and Fourslash harnesses, and LSP API-session initialization is unported. Source 75 increased peak RSS by
about 20% on a synthetic two-builder graph; the port log records the measurement and mitigation review.

Install the native compiler with `pnpm add -D tsrs@0.19.0-ts7.1.0-beta`.
Install WebAssembly with `pnpm add @tsrs/wasm@0.19.0-ts7.1.0-beta`.

The release pipeline adds prebuilt Intel macOS (`@tsrs/darwin-x64`) and Windows x64 (`@tsrs/win32-x64`) packages.
