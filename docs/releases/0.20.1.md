# 0.20.1

tsrs 0.20.1 is a patch release targeting TypeScript 7.1 beta. The TypeScript source pin remains
`microsoft/TypeScript@3e9236361fa9`, with the same TypeScript-compatible defaults and opt-in `--fast` preset as 0.20.0.

```sh
pnpm add -D tsrs@0.20.1-ts7.1.0-beta
# WebAssembly for Node and browsers:
pnpm add @tsrs/wasm@0.20.1-ts7.1.0-beta
```

- **Checker correctness.** Reverts a union-constraint shortcut whose cached type-variable flag could miss
  `NoInfer` constituents. Narrowing checks each constituent again (#808).
- **WebAssembly hosts.** Host and WASI memory accesses treat pointers at or above 2 GiB as unsigned, including
  request and response buffers, filesystem transfers, environment variables and output (#812).
- **Checker and collection storage.** Small union-merge buffers and inference flags use inline storage;
  concurrent maps allocate shard groups on demand, generic link stores use smaller chunks, and language-server
  file events use Fx hashing while preserving order (#800, #804). The
  [small-buffer](../../notes/data-structure-followups.md) and
  [collection](../../notes/data-structure-redesigns.md) notes record individual measurements and tradeoffs.
- **Scheduling and filesystem work.** Checker threads are reused across work groups, build modification-time
  caches are shared across builders without a single lock, and small include trees are read inline before
  falling back to the Rayon pool (#814, #815, #816).
- **Release publishing.** GitHub releases are marked as the latest release. npm packages continue to use the
  `latest` tag, and the playground deploys after publication (#801).
- **Benchmark documentation.** The [benchmark report](../../bench/RESULTS.md) compares published 0.20.0 packages
  with and without `--fast` against TypeScript 7.1 beta, with reproducible chart data (#805).

Supported platforms and known limitations remain listed in the [compatibility table](../COMPATIBILITY.md).
The linked optimization measurements describe individual changes, not a new packaged-release performance comparison.
