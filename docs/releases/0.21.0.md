# 0.21.0

tsrs 0.21.0 targets TypeScript 7.1 beta and adds a type-aware linter for Oxlint. The TypeScript source pin remains
`microsoft/TypeScript@3e9236361fa9`, with the same TypeScript-compatible defaults and opt-in `--fast` preset as 0.20.1.

```sh
pnpm add -D tsrs@0.21.0-ts7.1.0-beta
# WebAssembly for Node and browsers:
pnpm add @tsrs/wasm@0.21.0-ts7.1.0-beta
```

- **Type-aware linting for Oxlint.** tsrs implements tsgolint's headless protocol and all 61 of its type-aware
  rules at v7.0.2005 ([#624]). The `tsrs` package ships the linter inside the `tsrs` binary as `tsrs --lint`, with a
  `tsrs-lint` command that `oxlint --type-aware` runs through `OXLINT_TSGOLINT_PATH=node_modules/.bin/tsrs-lint`;
  release builds include lint in PGO training on every platform ([#857]). See
  [type-aware linting](../../tools/tsgolint/README.md).
- **Lint memory.** Rules run on the program's checker pool with the CLI's checker count and file assignment, so
  checkers no longer resolve most of the program once per thread; `TSRS_FAST=1` applies the fast preset ([#848]).
  The linter reads the default libraries from `TSRS_LIB_PATH` when it is set, as the CLI does ([#862]).
- **Lint file reads.** Disk contents, including empty files and failed reads, are cached for each request;
  source overrides take precedence, and later requests observe disk changes ([#874]).
- **Checker performance.** Key-property lookups skip resolving property types that cannot be unit types ([#859]),
  declaration and JSDoc paths avoid redundant allocations ([#833]), and symbol tables store keys that differ from
  the symbol's name as name proxies, ported from [microsoft/TypeScript#64979] ([#829]).
- **Language server.** A server dropped without a shutdown request frees its session, snapshots and programs
  ([#837]).
- **Maintenance.** The TypeScript nightly sync workflow ([#685]), lint benchmarks on pull requests that change the
  linter ([#853]), and dependency updates ([#865], [#866], [#867]).

Supported platforms and known limitations remain listed in the [compatibility table](../COMPATIBILITY.md).
