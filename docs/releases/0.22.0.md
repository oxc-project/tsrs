# 0.22.0

tsrs 0.22.0 targets TypeScript 7.1 beta. The TypeScript source pin remains `microsoft/TypeScript@3e9236361fa9`, with
the same TypeScript-compatible defaults and opt-in `--fast` preset as 0.21.0.

```sh
pnpm add -D tsrs@0.22.0-ts7.1.0-beta
# WebAssembly for Node and browsers:
pnpm add @tsrs/wasm@0.22.0-ts7.1.0-beta
```

- **Content mappers in the language server and the Node API.** `tsrs --lsp` and `tsrs --api --runExternalCode` run
  `contentMappers`, so mapped files such as `.vue` check in editors and through rolldown-plugin-dts's
  `generator: "tsrs"`, with diagnostics at their original positions ([#885], fixing [#877]).
- **Content mappers in the linter.** `tsrs --lint --runExternalCode`, or `TSRS_LINT_RUN_EXTERNAL_CODE=1` under
  Oxlint, lints programs whose tsconfig has `contentMappers` instead of reporting a tsconfig error. Type errors in
  mapped files are reported at their original ranges, and rules skip mapped files ([#883], fixing [#876]).
- **One lint pass instead of a separate typecheck.** Under `--fast`, `TSRS_LINT_CHECK_PROGRAM=1` makes the type errors
  reported with Oxlint's `--type-check` match `tsrs --noEmit` for each tsconfig program: files Oxlint did not send are
  checked too, and files outside every tsconfig are linted but not type-checked ([#897]).
- **Incremental runs under `--fast`.** Fast-mode build info records which files declare an interface, so an edit to
  a file without one no longer rechecks every interface-declaring file when a run starts from a tsbuildinfo ([#900]).
- **Fast-mode checker performance.** Conditional-type simplification resolves the false branch first, and literal
  indexes into fixed tuples are answered from the tuple's type arguments, ported from
  [teamchong/TypeScript#1] ([#854]).
- **Maintenance.** Determinism CI runs in shards and the lint baselines run in parallel ([#875]).

Supported platforms and known limitations remain listed in the [compatibility table](../COMPATIBILITY.md).
