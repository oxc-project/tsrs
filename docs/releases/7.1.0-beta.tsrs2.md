# 7.1.0-beta.tsrs2

This release targets TypeScript `7.1.0-beta`, pinned to `microsoft/TypeScript@3e9236361fa97a9e6c685f4833ac457ae2d8c50a`.
It is the first npm release with [TypeScript-aligned versions](7.1.0-beta.tsrs1.md). `7.1.0-beta.tsrs1` reached
crates.io, but its npm publication stopped at the installed-package smoke test, which still expected the
`0.25.0-ts7.1.0-beta` format ([#1000]). Cargo crates and all ten npm packages share version `7.1.0-beta.tsrs2`.

npm prereleases use the `next` tag, so `latest` stays on `0.25.0-ts7.1.0-beta`. Install this release by version:

```sh
pnpm add -D tsrs@7.1.0-beta.tsrs2
pnpm add @tsrs/wasm@7.1.0-beta.tsrs2
```

## Linting

- `tsrs-lint` and `tsrs --lint` enable the fast preset by default ([#989]). `TSRS_FAST=0` opts out; per-feature
  environment overrides still take precedence.
- `oxlint --type-check` reports compiler diagnostics only for the files Oxlint selected for linting, as tsgolint does
  ([#998]). Files excluded by ignore patterns, CLI path selection or `tsconfig.exclude` still provide type information
  but no longer fail lint. Program-wide global diagnostics are no longer reported on the tsconfig.
- `no-misused-promises` accepts `checksConditionals: { flagUnions: "none" | "strict" | "all" }`, matching
  typescript-eslint 8.69.0 ([#988]).
- A relative type reference from a type root into a symlinked package no longer panics when the program has project
  references ([#999]). Vue projects using pnpm hit this through the generated global types reference.

## Release builds

PGO training, and BOLT training on Linux, now include `tsrs -p . --fast`, so the code paths the fast preset enables are
no longer laid out as cold ([#976]). Release binaries build with Rust 1.100.0, and the published crates now require
Rust 1.100 ([#990]). Rust dependencies were updated ([#997]).

The compiler continues to report TypeScript `7.1.0-beta` for compatibility. Packages are available for macOS
arm64/x64, Linux x64/arm64 (glibc and musl), and Windows x64/arm64.
