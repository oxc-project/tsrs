# 7.1.0-beta.tsrs3

This release targets TypeScript `7.1.0-beta`, pinned to `microsoft/TypeScript@3e9236361fa97a9e6c685f4833ac457ae2d8c50a`.
It is the first TypeScript-aligned release published under npm's `latest` tag ([#1014]), so a default install now gets
it instead of `0.25.0-ts7.1.0-beta`:

```sh
pnpm add -D tsrs@7.1.0-beta.tsrs3
pnpm add @tsrs/wasm@7.1.0-beta.tsrs3
```

## Linting

- `oxlint --type-check` no longer reports suggestion diagnostics. Oxlint showed them as errors, so suggestions from
  plugins like Effect's language service failed lint. Message diagnostics such as TS1450, which `tsc` fails on, are
  still reported ([#959]).
- Type errors include the message chain, the extra lines that explain the error, as `tsc` prints it. `tsconfig-error`
  reports put the chain in their help text ([#1006]).
- Two performance changes: headless diagnostics are serialized without building an intermediate JSON value tree
  ([#1011]), and `no-unsafe-enum-assignment` no longer recursively compares prototype members when both constrained
  types share a primitive wrapper ([#1012]).

## Compiler

These fixes match tsgo:

- A file that references itself without an extension, such as `/// <reference path="a" />` in `a.ts`, reports TS1006
  ([#1023]).
- With `"files": ["a.ts"]` and `"include": ["*.d.ts"]`, `a.d.ts` is no longer part of the program, and overlapping
  `files` and `include` entries no longer repeat the `Part of 'files' list` reason ([#1021]).
- With `declaration: true`, a type from `lib/index.ts` keeps `import("./lib/index")` when `lib.ts` also exists
  ([#1024]).
- `tsrs -p sub` and `tsrs -b sub` no longer report TS5011 for a declaration-only project with `outDir`. The check
  uses the config directory instead of the working directory ([#1022]).
- `tsrs -b` writes `"root":[]` to `.tsbuildinfo` for a non-incremental project with no input files ([#1025]).
- The language server resolves type roots for documents that are not `file:` URIs, such as `untitled:` files and
  virtual workspaces ([#1009]).

The compiler continues to report TypeScript `7.1.0-beta` for compatibility. Packages are available for macOS
arm64/x64, Linux x64/arm64 (glibc and musl), and Windows x64/arm64.
