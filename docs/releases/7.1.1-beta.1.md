# 7.1.1-beta.1

tsrs versions now identify the supported TypeScript release, following [#961](https://github.com/oxc-project/tsrs/issues/961).
This release targets TypeScript `7.1.0-beta`, pinned to `microsoft/TypeScript@3e9236361fa97a9e6c685f4833ac457ae2d8c50a`.

Cargo crates and all ten npm packages share version `7.1.1-beta.1`. npm prereleases use the `next` tag:

```sh
pnpm add -D tsrs@7.1.1-beta.1
pnpm add @tsrs/wasm@7.1.1-beta.1
```

This replaces npm's `0.25.0-ts7.1.0-beta` version format. Stable TypeScript `7.0.2` maps to tsrs `7.0.2001`, with
subsequent tsrs fixes incrementing the last three digits. Prerelease fixes increment the final identifier, so the
next fix for the current reference is `7.1.1-beta.2`. See [versioning](../RELEASING_CRATES.md#versioning) for nightly
handling, ordering and suffix limits.

The compiler continues to report TypeScript `7.1.0-beta` for compatibility. Its exact source pin remains available
in the CLI's `--version` output and npm package metadata.
